# CropGuard

CropGuard is a deep learning-based crop disease detection project.

## Tech Stack
- Python
- PyTorch
- Torchvision
- Git

## Model
- ResNet18 (Transfer Learning)

## Dataset
- PlantVillage Tomato Disease Dataset

## Project Structure
- data/
- src/
- tests/
- docs/

## Goal
Detect tomato leaf diseases from images using computer vision.
## Features

- Tomato Disease Classification
- Transfer Learning using ResNet18
- Image Preprocessing
- Model Training & Evaluation
- FastAPI Backend (Planned)
- Streamlit Frontend (Planned)

## Future Improvements

- Multi-crop support
- Mobile deployment
- Real-time disease detection
